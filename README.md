# 🏠 21天 · 快乐一家人打卡神器

> 用 21 天，养成更和谐的相处方式。

## 设计理念

「21 天养成一个习惯」—— 这个项目借用这个心理学概念，设计了 21 个循序渐进的小任务，
让两个人（伴侣、家人、室友）在每天的互动中重新发现彼此的好，培养更和谐的相处习惯。

**这不是一个监督工具，而是一份相处的仪式感。**

## 怎么玩

### 三步开始

1. **打开页面** → 看到欢迎屏
2. **输入你们的名字** → 各自选一个喜欢的表情符号
3. **点击"出发"** → 开始 21 天的旅程

### 每日流程

| 步骤 | 内容 | 说明 |
|------|------|------|
| ① | **查看今日任务** | 每天有一个专属小任务，难度和深度三周递进 |
| ② | **各自打卡** | 每人点击自己的名字，标注"已完成"✅ |
| ③ | **记录心情** | 从 😄😊🙂😐😞 中选一个代表今天的心情 |
| ④ | **互相评分** | 双方都完成打卡后，给今天的和谐度打 1-5★ |
| ⑤ | **写每日心声** | 写下今天想对对方说的话 |
| ⑥ | **进入下一天** | 双方都完成后，解锁第二天 |

### 三周主题

```
第 1 周 · 重新认识彼此  —— 感恩、观察、倾听
第 2 周 · 深度连接      —— 分享、付出、互动
第 3 周 · 共创未来      —— 规划、承诺、庆祝
```

### 查看进度

- **「进度」标签页** → 21 天日历格，完成变绿，未完成灰色。底部显示统计数据
- **「日记」标签页** → 时间线回顾，所有写过心声的每一天
- **点击任意格子** → 查看那一天的详细记录
- **顶部和谐度评分** → 所有评分的平均值，实时更新

## 关于数据

所有数据存储在浏览器的 `localStorage` 中，存在你本地，不会上传到任何服务器。
如果清除浏览器缓存则会丢失数据。

## 21 天任务一览

### 第 1 周 · 重新认识彼此

1. 真诚地感谢对方为你做的一件小事，并告诉对方
2. 放下手机，和对方一起专注地吃一顿饭（至少 20 分钟）
3. 写下对方的 3 个优点，念给对方听
4. 主动做一件对方平时负责的家务
5. 问对方："今天有什么需要我支持你的吗？"
6. 一起看一张老照片，分享当时的回忆
7. 给对方一个拥抱，至少持续 20 秒

### 第 2 周 · 深度连接

8. 为对方准备一个小惊喜
9. 一起做一顿饭，分工合作
10. 聊聊各自的童年：最快乐的回忆是什么？
11. 给对方一个真诚的道歉
12. 一起出门散步 15 分钟，手牵手
13. 写下对方的梦想，讨论你可以如何支持
14. 给对方按摩肩膀或背部 5 分钟

### 第 3 周 · 共创未来

15. 一起聊聊：我们各自最欣赏对方的哪个习惯？
16. 为对方朗读一段文字
17. 一起规划一件未来想做的事
18. 写下"我希望我们能一直……"的 3 个句子
19. 做一件对方喜欢但你平时不太主动做的事
20. 给对方写一封短信，说说这 21 天里的感受
21. 一起庆祝！回顾这 21 天，给对方一个最走心的感谢
